# tasapainovertailu
Tasapainorahastojen kuukausivertailu vs. 50/50 ETF (SPYI+VAGF)

Sivusto lukee `history.json`:n. Kenttäkuvaus ja päivitysprosessi: [SCHEMA.md](SCHEMA.md). Aiemmat versiot: `revisions/<kausi>/rNNN.json` ja git-historia.
Testi: `python3 tests/test_history.py`. Paikallinen esikatselu: `python3 -m http.server` ja `index.html?local`.
